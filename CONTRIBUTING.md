# Contributing

A useful skill encodes **repeatable expert judgment**, not “act as a senior engineer.”

Rules:
1. One primary capability per skill.
2. The description must say what the skill does and when it should activate.
3. Workflows must include evidence, decisions, failure modes, and exit criteria.
4. Prefer composition over copying another skill into a new one.
5. Keep tool-specific detail in references/scripts/assets when it is large.
6. Preserve the Agent Skills frontmatter contract.
7. Run `python3 scripts/validate.py`.
8. Add positive and negative routing examples for ambiguous new skills.
