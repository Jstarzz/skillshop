# Public references and design influences

The skill text in this repository is original wording. Public sources were used to validate format choices, marketplace structure, and useful categories/patterns rather than copied wholesale.

- Agent Skills specification — https://github.com/agentskills/agentskills  
  `SKILL.md` structure, metadata constraints, optional resources, and progressive disclosure.
- Anthropic Claude Code official plugin marketplace — https://github.com/anthropics/claude-plugins-official  
  Marketplace and plugin layout examples.
- secondsky/claude-skills — https://github.com/secondsky/claude-skills  
  Large categorized skill catalogs and per-skill resources.
- jeffallan/claude-skills — https://github.com/jeffallan/claude-skills  
  Specialist development skills and context-aware activation patterns.
- addyosmani/agent-skills — https://github.com/addyosmani/agent-skills  
  Workflow-oriented skill design emphasizing process and verification.
- Public systematic-debugging skills (including ChrisWiles-derived community versions)  
  Root-cause-first debugging as a reusable skill.
- Public TDD skills  
  Red/green/refactor and behavior-first testing.
- Public verification-before-completion skills  
  Fresh evidence before a completion claim.
- Public brainstorming/design-shaping skills  
  Comparing materially different approaches before implementation.

If third-party skill text is ever vendored verbatim later, preserve its license and provenance. This repository currently re-implements general ideas in its own wording.
