# Suggested skill compositions

These are examples, not mandatory bundles.

## New SaaS feature
`project-profiler` → `requirements-to-tasks` → (`technical-feasibility` + `ux-feasibility` where needed) → `implement-feature` → `qa-orchestrator` → `verification-before-completion`

## Architecture proposal
`caveman` + `future-proof` + `paranoid` + `cheap-ass` → `architecture-review` → `decision-record`

## Intermittent production bug
`bug-reproducer` → `systematic-debugging` → optional `race-hunter` / `bad-network` / `dependency-failure` → `fix-bug` → `regression-suite`

## Payment feature
`payment-integrity` + `transaction-review` + `idempotency-review` + `webhook-security` → `qa-orchestrator` → `load-test` if throughput matters

## Release
`requirements-audit` → `release-candidate-qa` + selected `security-review` / `load-test` → `production-readiness` → `rollback-review` → `release-manager`

## Recorded QA flow to performance test
`journey-recorder` → `journey-compiler` → `load-modeler` → `generator-sanity` → `load-test` → optional `take-my-load-operator` → `regression-analysis`

## UI quality pass
`grandma` + `frontend-slop-obliterator` + `pixel-cop` + `responsive-review` + selected `accessibility-tester` / `one-handed` / `low-end-device`
